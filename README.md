# Understory Kelp Indicator

## Overview

This repository contains code, data-processing workflows, analytical outputs, figures, and LaTeX materials associated with the development of an **Understory Kelp Indicator** for Puget Sound, Washington. 
With funding from Puget Sound Partnerships, [Reef Check](https://www.reefcheck.org/kelp-forest-program/) and the [Seattle Aquarium](https://www.seattleaquarium.org/) are working to co-develop an first instantiation of a Understory Kelp Abundance and Condition Indicator. 
This initial effort focuses on subtidal kelp species and draws primarily from Reef Check scuba diver survey data, with complementary support from Seattle Aquarium ROV surveys and other compatible data sources where available.

This project is part of a broader effort to support Puget Sound Partnership [Vital Signs](https://vitalsigns.pugetsoundinfo.wa.gov/) reporting by developing a repeatable, transparent, and data-driven indicator for subtidal kelp abundance and condition.

Puget Sound’s existing kelp Vital Sign reporting has historically focused on floating canopy-forming kelps, such as bull kelp and giant kelp via the [Floating Kelp Indicator](https://experience.arcgis.com/experience/26b6d44bdef04470ad49cf42a8a2c585). 
These surface-canopy indicators are essential for tracking widespread changes in canopy-forming kelp beds, but they do not capture trends in the many kelp species that occur below the surface. 
Because much of Washington’s kelp diversity occurs in the understory, the lack of a subtidal, non-canopy kelp indicator represents an important information gap for monitoring, management, and recovery planning.

The purpose of this repository is to organize the reproducible code and reporting tools used to process Reef Check diver data, Seattle Aquarium remotely operated vehicle (ROV) data, and other compatible datasets into spatially explicit metrics, figures, and reporting products for the Understory Kelp Indicator.
